## **🚀 GitHub Setup**

### Before Upload
- [ ] Create GitHub account (if don't have one)
- [ ] Create repository named: `portfolio`
- [ ] Make repository: **PUBLIC**

### Upload Files
- [ ] Upload `index.html`
- [ ] Upload `style.css`
- [ ] Upload `script.js`
- [ ] Upload `README.md`
- [ ] Upload `DEPLOYMENT_GUIDE.md` (optional)
- [ ] Upload entire `assets/` folder with:
  - [ ] `img/` subfolder with all images
  - [ ] `cv/` subfolder with PDF

### Enable GitHub Pages
- [ ] Go to Settings → Pages
- [ ] Select: **Source = main branch**
- [ ] Select: **Folder = / (root)**
- [ ] Click **Save**
- [ ] Wait 2-5 minutes for deployment

### Verify Live Site
- [ ] Visit: `https://YOUR-USERNAME.github.io/portfolio`
- [ ] Check all sections load
- [ ] Test navigation
- [ ] Verify images display
- [ ] Test all links

## **💡 Pro Tips**

1. **Before uploading to GitHub**, test everything locally by opening `index.html` in your browser
2. **Use Chrome DevTools** (F12) to check for console errors
3. **Keep backups** of your original files before making changes
4. **Update regularly** - portfolios get stale; add new projects quarterly
5. **Share widely** - LinkedIn, Twitter, GitHub, resume, business cards
6. **Ask for feedback** - Get opinions from mentors, peers, friends
7. **Monitor traffic** - GitHub Pages doesn't have built-in analytics; consider Google Analytics
