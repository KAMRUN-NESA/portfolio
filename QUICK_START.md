## **Step 3: Test Locally (2 min)**

1. **Double-click** `index.html` to open in browser
2. Scroll through all sections
3. Test navigation menu
4. Check mobile view (press F12, then mobile icon)
5. Verify images load

---

## **Step 4: Create GitHub & Upload (2 min)**

**A. Create Repository:**
1. Go to https://github.com/new
2. Name it: `portfolio` (exactly!)
3. Make it PUBLIC ⚠️
4. Click Create

**B. Upload Files:**
1. Click "Upload files" on GitHub
2. Drag your entire portfolio folder here
3. Commit changes

---

## **Step 5: Enable GitHub Pages (1 min)**

1. Go to your repository → **Settings**
2. Find **Pages** in left sidebar
3. Select **Source: main branch**
4. Save and wait 2-3 minutes

✅ **Your site is now LIVE at:**
```
https://YOUR-USERNAME.github.io/portfolio
```

## **⚠️ Common Mistakes**

❌ Repository is Private → ✅ Make it PUBLIC
❌ Images in wrong folder → ✅ Use `assets/img/` and `assets/cv/`
❌ Forgetting to enable Pages → ✅ Settings → Pages → main branch
